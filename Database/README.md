# Database setup

يحتوي هذا المجلد على مخطط قاعدة البيانات التي يعتمد عليها التطبيق، من دون أي بيانات شخصية أو سجلات طلاب.

## إنشاء قاعدة جديدة

1. افتح SQL Server Management Studio.
2. اتصل بالخادم الذي سيعمل عليه التطبيق.
3. افتح الملف `Scripts/001_CreateSchema.sql`.
4. نفّذ السكربت مرة واحدة؛ سينشئ قاعدة باسم `SchoolSystemDatabase` إن لم تكن موجودة، ثم ينشئ الجداول والعلاقات.
5. اضبط `Data Source` في `SchoolSystem.Presentation/App.config` على اسم الخادم نفسه.

السكربت لا يحذف قاعدة موجودة ولا يحذف جداول أو بيانات. كما أنه لا يضيف البيانات الحالية للأشخاص والطلاب والمعلمين.

## البيانات المرجعية

المخطط وحده قابل لإعادة الإنشاء، أما البيانات المرجعية مثل الدول والمراحل والمواد وصفحات القرآن فلا تُنسخ من قاعدة التطوير تلقائيًا. بعد اختيار مجلد القرآن وتشغيل المزامنة، يضيف التطبيق الصفحات أو يحدّث مساراتها لتطابق الجهاز الحالي.

## ملاحظات المخطط الحالي

- احتُفظ بالعمودين `ParentSubjectID` و`ParentID` في جدول `Subjects` لأن الكود والمخطط الحاليين يستخدمانهما بأدوار مختلفة.
- أزيل من سكربت الإنشاء تكرار غير ضروري لعلاقة `Grades.StageID`؛ السكربت ينشئ علاقة واحدة باسم `FK_Grades_Stages`.
- لا توجد إجراءات مخزنة خاصة بالتطبيق؛ طبقة البيانات تستخدم استعلامات ADO.NET مباشرة.
