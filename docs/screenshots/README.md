# Portfolio screenshot checklist

Use only demo data when creating screenshots. Do not publish real names, phone numbers, email addresses, national numbers, personal photos, or student progress.

## Recommended captures

| File name | Screen | What the image should show |
| --- | --- | --- |
| `01-main-dashboard.png` | Main form | The four main navigation areas and application identity |
| `02-academic-structure.png` | Education structure | Stages, grades, and sections in the tree layout |
| `03-subject-tree.png` | Subject hierarchy | Parent and child subjects without student-identifying data |
| `04-quran-progress.png` | Quran progress | Page states and track workflow using a clearly fictional student |

## Capture guidelines

- Use a consistent window size, preferably 1600×900 or 1920×1080.
- Keep the application window centered and remove unrelated desktop content.
- Use the same theme and zoom level in every image.
- Avoid open error dialogs, Visual Studio, SQL Server Management Studio, and connection settings.
- Verify every visible record before committing a screenshot.
- Save PNG files in this directory using the filenames above.

After adding the images, embed them in `PORTFOLIO.md` beneath the **Screenshots** heading.
